# Asset Strategy

This repository should keep image assets simple and intentionally managed as static files.

## Recommendations

- Prefer WebP or AVIF for new photography and marketing imagery where browser support is acceptable.
- Keep PNG for transparent or detailed graphic assets when needed.
- Use responsive image sets for hero and marketing imagery to serve appropriately sized files.
- Record a target width for each major image to avoid oversized downloads.
- Compress future imagery carefully to preserve visual quality while reducing transfer size.
- Treat hero images differently from secondary decoration images: keep them visually intentional and optimized for first-load experience.

This document is a planning reference only; no asset conversion is performed during active page design work.
