# Client Portal Roadmap

## Phase 1 — Interface shell

- establish the application shell pattern and navigation structure
- build client and admin workspace layouts
- define empty states and preview-only language
- keep all routes non-public and noindex

## Phase 2 — Authentication

- add secure server-backed login flow
- implement session handling and role retrieval
- apply backend authorization checks to protected routes and APIs

## Phase 3 — Client and service records

- link users to client records
- manage active service engagements and their related tasks
- support client details and contact preferences

## Phase 4 — Secure documents

- add private storage and access control
- add upload/download flows behind authenticated routes only
- log document activity and retention actions

## Phase 5 — Appointments and messaging

- add scheduling flows or integrations
- move communication into authenticated and auditable channels
- support staff/client messaging with permissions and retention rules

## Phase 6 — Billing and operational oversight

- connect invoicing and payment processing through approved providers
- add admin reporting and operational dashboards
- expand audit and retention capabilities

## Current status

This repository is in Phase 1. The client and admin interfaces are present as design-ready shells with clear preview language, but no authentication, session logic, data persistence, or real document storage has been introduced.
